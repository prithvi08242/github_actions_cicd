Step-by-Step: Upload Your HTML Project to GitHub and Publish It
Step 1: Create a New Repository
Open GitHub.
Click New Repository.
Repository Name: devops-journey
Select Public.
Check Add a README file.
Click Create Repository.
Step 2: Add the HTML File
Inside the repository, click Add file → Create new file.
In the filename box, type:
index.html

Important: The file must be named index.html so GitHub Pages can display it automatically.

Paste the full HTML code I provided.
Scroll down and click Commit new file.
Step 3: Enable GitHub Pages
Click the Settings tab.
In the left sidebar, click Pages.
Under Build and deployment:
Source: Deploy from a branch
Branch: main
Folder: / (root)
Click Save.
Step 4: Wait for Deployment

GitHub will build and publish your website. This usually takes 1–3 minutes.

Step 5: Open Your Website

Your website will be available at:

https://YOUR_GITHUB_USERNAME.github.io/devops-journey/

For your GitHub username, the URL should look like:

https://prithvi08242.github.io/devops-journey/
